## 1. AI agents

- Microsoft took its Agent Framework repository offline and posted a security advisory on November 25: two unauthorized Python package releases (1.26.1 and 1.26.2) uploaded to PyPI contained credential-stealing code. Microsoft removed the uploads and gave remediation steps; no restore date was given ([AI Agents News](https://aiagentstore.ai/ai-agent-news/this-week)).
- Cloudflare launched "Search for Agents" on November 25, a one-click toggle that indexes a domain and exposes a `/.well-known/search` endpoint returning Markdown results, so agents can discover site content without crawling ([AI Agents News](https://aiagentstore.ai/ai-agent-news/this-week)).
- Anthropic updated the Model Context Protocol with server-provided "Skills" (public beta), long-running asynchronous Tasks (GA), Elicitation pauses for user confirmation (GA), and file uploads that bypass model context ([AI Agents News](https://aiagentstore.ai/ai-agent-news/this-week)).
- The FCC approved SpaceX's orbital AI data center constellation, and Anthropic published an account of using Claude agents to migrate its API to Rust ([The Neuron](https://www.theneuron.ai/digest/everything-that-happened-in-ai-today-november-26-2026/)).
- Field reports show agent infrastructure maturing: iFood runs coding agents across 15,000 repositories with permission boundaries and rollback, and payment rails are being wrapped as MCP tool calls with explicit approval flows ([mech.app](https://www.mech.app/briefs/2026-11-26-daily-brief/)).

## 4. Software development

- React Router shipped fixes for 7 vulnerabilities (4 high, 3 moderate); users should upgrade to 7.18.6 or 8.5.2. An automated "React2STEAL" campaign is actively exploiting unpatched React and Next.js servers from hijacked GitHub accounts: at least 1,281 servers vulnerable to React2Shell (React 19.0-19.2) or the Next.js middleware bypass had env vars and API keys committed to public repos ([This Week In React](https://thisweekinreact.com/newsletter/307)).
- Next.js is experimenting with "Switchyard", a Go server in front of `next start`; routing could eventually move to it, and experimental Go Route Handlers would skip Node entirely ([This Week In React](https://thisweekinreact.com/newsletter/307)).
- TanStack Query published its v6 roadmap: ESM-only, React 19 minimum, `use()`-based Suspense, microtask scheduler, deprecated APIs removed ([This Week In React](https://thisweekinreact.com/newsletter/307)).
- Node.js is preparing to enable pointer compression by default, and Ricky Hanlon left Meta after 8 years on React core ([This Week In React](https://thisweekinreact.com/newsletter/307)).
- Cognition shipped Devin 2026.11.25: element picking in the Devin Apps browser tab, full PR review page, and faster clones via blueprint clone.filter ([Havoptic](https://www.havoptic.com/r/devin-2026-11-25)).

### How you could make money from this

Recruiters searching for the vulnerability will find your GitHub; it also gives you a concrete security story for interviews.
