## 3. Finland's border security

- President Zelenskiy confirmed on 24 November that Ukraine carried out the 21 November drone strike on the Russian cargo ship Sparta II in the Gulf of Finland, calling every Russian-flagged weapons or sanctioned-cargo carrier "a legitimate target", while Norway publicly urged Ukraine to avoid operations that destabilize the Baltic. The ship has been towed back and is anchored off St Petersburg. ([Reuters via US News](https://www.usnews.com/news/world/articles/2026-11-24/norway-says-there-is-dialogue-with-ukraine-regarding-need-for-stability-in-our-near-areas))
- Finland's National Enforcement Authority said on 23 November that Sparta II has connections to an EU-sanctioned entity (Oboronlogistika, tied to Russia's Defence Ministry); it imposed a temporary restriction on the vessel on Saturday evening but allowed its release under maritime-rescue and environmental exceptions. The ship was permitted to leave Finnish waters on Sunday. ([Defence Matters](https://defencematters.eu/finland-sparta-ii-sanctions-drone-strike-baltic-maritime/))
- The Border Guard's investigation continues into the suspected violation of Finnish airspace by a Russian helicopter off Loviisa on 21 November, which penetrated up to 4.1 km into Finnish territory, possibly linked to the Sparta II rescue. ([Nordic Defence Sector](https://nordicdefencesector.com/en/article/russian-helicopter-suspected-of-violating-finnish-airspace), [Finnish Border Guard news](https://raja.fi/en/news-and-press-releases?p_r_p_resetCur=false))
- Background (older, still current policy): Finland's eastern land border remains closed until further notice under the Government's renewed decision of 4 June 2026, with authorities assessing that instrumentalised migration would likely resume if crossings reopened. ([Ministry of the Interior](https://intermin.fi/en/-/finland-s-eastern-border-to-remain-closed-until-further-notice-2?languageId=en_US))

## 4. Software development

- Google Workspace rolled out managed MCP servers plus a command-line tool for building agents, with standardized API usage tiers and admin policies for access, confirmation, data protection and auditing (release notes dated 24 November). This drags MCP from a developer-ecosystem curiosity into managed enterprise territory. ([Releasebot](https://releasebot.io/updates/google))
- OpenCode v2.4.0 shipped 23 November with a built-in desktop browser that imports logins from Chrome/Edge/Firefox/Safari and lets the agent read and drive the same pages, plus timer/cron/MCP-event automations and a `generate_video` tool when a connected provider has a video model. ([Agent Tools Today](https://munderdiffl.in/blog/agent-tools-today-2026-11-24/))
- OpenAI and Cisco launched Shirudo on 23 November, an open-source runtime that shields running Linux systems against exploit attempts without waiting for patches or restarts; in a controlled test a Codex-generated shield blocked a Java4Shell attempt against a live Elasticsearch service. ([Agent Tools Today](https://munderdiffl.in/blog/agent-tools-today-2026-11-24/))
- Claude Code v2.1.331 (23 November) added Code Mode on Amazon Bedrock and Microsoft Foundry, and fixed MCP tool calls hanging up to 30 minutes on malformed local/WebSocket server replies; OpenAI Codex CLI 0.172.0 (24 November) made optional stdio MCP servers start on first tool call and added per-tool approval reviewers. ([DevAgentRadar](https://www.devagentradar.com/insights/radar-brief-2026-11-24), [Agent Tools Today](https://munderdiffl.in/blog/agent-tools-today-2026-11-24/))

### How you could make money from this

- MCP server development is currently the single highest-signal skill for a junior with TypeScript/Python. Google shipping managed MCP support means every Finnish enterprise integrator (Gofore, Eficode, Nitor, Futurice) will need people who can wrap a legacy API in an MCP server. Build one for a real API in your GitHub portfolio this week; that is a one-line interview answer that stands out.
- NixOS angle: OpenCode, Codex and Claude Code all ship as CLI tools whose environments break constantly; publishing Nix flake packages/overlays for the current agent CLIs is an unoccupied niche matching your daily-driver OS and directly useful to companies running agent toolchains reproducibly.
- YouTube tutorial target: "Build an MCP server in TypeScript in 30 minutes (and plug it into Claude and Gemini)" in Finnish or English. The DevConf-style content is saturated in English but MCP is new enough that a current, working 2026 tutorial ranks; the resulting repo watchers are also job-market signal.
